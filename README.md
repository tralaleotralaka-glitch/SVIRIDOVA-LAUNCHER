# NEXUS — неоновый лаунчер для Android

Нативный лаунчер (домашний экран) в стиле HUD / cyberpunk: тёмное стекло,
неоновые акценты, крупные часы, живые обои и собственные Canvas-виджеты.
Написан на Kotlin без Compose и без AppCompat — только `androidx.core`,
`recyclerview`, `viewpager2`.

## Что внутри

| Экран | Возможности |
| --- | --- |
| Рабочий стол | Крупные часы с секундами и датой, поиск по приложениям, виджет погоды, заряд батареи, заметки, листаемая сетка приложений (4–6 столбцов), док с быстрыми действиями |
| Поиск | Мгновенная фильтрация приложений, Enter запускает первый результат |
| Долгое нажатие | Системное меню: «Информация о приложении», «Удалить» |
| Заметки | Выдвижная панель: добавление и удаление заметок прямо на рабочем столе |
| Настройки | 6 акцентных цветов, 5 обоев, 4 формы иконок, свечение, число столбцов, секунды, подписи, вибрация, лаунчер по умолчанию, сброс |

### Живые обои (собственная отрисовка, без библиотек)

- **Сетка** — синтвейв-горизонт: солнце с прорезями, бегущие линии перспективы, звёзды.
- **Аврора** — плавающие цветовые поля и линии тока.
- **Матрица** — падающие глифы.
- **Частицы** — сеть точек с линиями.
- **Фон** — только градиент.

### Погода

Open-Meteo (без ключей и аккаунтов) + последняя известная геопозиция.
Без разрешения виджет остаётся в спокойном состоянии.

## Скачать готовый APK

Сборка автоматическая (GitHub Actions). Готовый файл лежит в релизах:

**https://github.com/tralaleotralaka-glitch/SVIRIDOVA-LAUNCHER/releases**

Файл: `NEXUS-launcher-1.0-<коммит>.apk`

1. Скачайте `.apk` с телефона (раздел «Assets»).
2. Разрешите установку из этого источника, если система спросит.
3. Нажмите «Домой» → выберите **NEXUS**.

Каждый push в `main` или `arena/**` заново собирает APK и обновляет релиз `apk-latest`.

## Сборка

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Требуется Android Studio (Ladybug или новее) либо JDK 17 + Android SDK 34.
`minSdk 26`, `targetSdk 34`.

Установка на телефон:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

После установки нажмите **Домой** и выберите **NEXUS** как лаунчер
(или «Настройки → Лаунчер по умолчанию» внутри приложения).

> Примечание: `gradle/wrapper/gradle-wrapper.jar` и шрифты — бинарные файлы,
> они уже лежат в репозитории. Проект собирается без дополнительных зависимостей,
> кроме AndroidX из Maven/Google.

## Веб-превью

`preview/index.html` — интерактивный макет дизайна (тот же стиль, те же цвета и
шрифты), чтобы посмотреть интерфейс без сборки APK. Открывается в браузере:

```bash
cd preview && python3 -m http.server 8000
# затем http://localhost:8000
```

В макете работают поиск, заметки, настройки (акцент, обои, формы иконок,
столбцы, свечение, секунды), долгое нажатие на иконку и перелистывание страниц.

## Проверка без Android Studio

В песочнице Arena нет JDK/Android SDK, поэтому APK здесь не собирается.
Что проверено автоматически:

- Kotlin-синтаксис всех 22 файлов (tree-sitter, парсер `tree-sitter-kotlin`);
- все ссылки на ресурсы `R.*` и `@*/*` из XML/манифеста разрешаются;
- манифест и все XML-файлы корректны, классы манифеста существуют;
- в проекте нет неиспользуемых импортов и «висячих» строк.

Для сборки на своей машине достаточно Android Studio и JDK 17.
